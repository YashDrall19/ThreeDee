# ⚡ Yash Drall — The Hogwarts 3D Developer Portfolio

> *"A Wizard Behind the Code"*

An immersive, award-winning-caliber 3D developer portfolio for **Yash Drall**, inspired by the visual storytelling, architecture, environments, and cinematic atmosphere of the eight Harry Potter movies.

Built with **Next.js 14**, **React Three Fiber (Three.js)**, **GSAP / Framer Motion**, **Tailwind CSS**, and the **Web Audio API**.

---

## 🏰 Experience Overview

- **Cinematic Entrance ("The Hogwarts Experience")**: Dark misty beginning, golden lumos wand sparks, camera flight approaching Hogwarts castle, and the enchanted archway portal ("ENTER THE WIZARDING WORLD").
- **Interactive 3D WebGL World**:
  - Detailed procedural Hogwarts Castle (Great Hall, Astronomy Tower, Dumbledore's Tower, turrets, viaduct bridge, black lake reflections).
  - Floating enchanted candles with flickering flames and warm ambient light.
  - Interactive Golden Snitch with high-fidelity metallic sheen and rapid wing kinematics that reacts to cursor movements.
  - Dynamic atmospheric particles and volumetric fog transitioning between the 8 movie themes.
- **The 8 Movie Chapters (Authentic Resume Content)**:
  1. **The Philosopher's Stone** — *The Awakening*: Hero introduction, value proposition, quick stats.
  2. **The Chamber of Secrets** — *Hidden Chambers*: Subterranean emerald glow, engineering philosophy, analytical background (DCRUST Biomedical Engineering, CGPA 8.04/10).
  3. **The Prisoner of Azkaban** — *Grimoire of Runes*: Technical skills categorized by magical disciplines (Frontend, Backend, Arcane AI & LLMs, Databases, Cloud & VPS, Security).
  4. **The Goblet of Fire** — *Trials of Honor*: Professional experience cards styled as Triwizard scrolls (Karma Ayurveda Pvt. Ltd., Talentiser).
  5. **The Order of the Phoenix** — *Room of Requirement*: Interactive magical project relics (ChatSpace AI Vault, GCC Circle, Purchase Order System, Tour Planner, Telecom System, Soccer Premier League) with modal deep-dives.
  6. **The Half-Blood Prince** — *The Pensieve*: Deep architectural systems breakdown (Multimodal Real-Time AI, Enterprise CRM & RBAC, Linux DevOps & VPS, Database Normalization & Indexing).
  7. **The Deathly Hallows Part 1** — *The Wandering Path*: Interactive luminous timeline of milestones and career progression.
  8. **The Deathly Hallows Part 2** — *The Final Destination & The Future*: Contact coordinates, Owl Post messaging dispatch, resume download, and the grand finale.
- **Audio & Sound Design**:
  - Web Audio API procedural celestial synth engine (Hedwig's waltz on celesta & mystical drones).
  - Built-in support for user-supplied legally licensed soundtrack at `/public/audio/background-theme.mp3`.
  - Subtle interactive sound effects (wand spell cast, sparkle chime, portal resonance, parchment rustle, owl hoot, snitch flutter).
  - Floating music controller with animated equalizer bars, volume slider, mute toggle, and preference persistence.
- **Magical Easter Eggs**:
  - **Marauder's Map Mode**: "I solemnly swear that I am up to no good" toggles live footprints following your cursor across the screen!
  - **Spell Casting Bar**: Cast `Lumos`, `Patronum`, or `Accio` for interactive screen effects.
  - Custom Wand Cursor with glowing Lumos torch.

## 🛠️ Technology Stack

- **Framework**: Next.js 14 (App Router, TypeScript)
- **3D Graphics**: Three.js, `@react-three/fiber`, `@react-three/drei`
- **Animations**: Framer Motion, GSAP, Canvas Confetti
- **Audio Engine**: Web Audio API Procedural Synthesizer + HTML5 Audio Loader
- **Styling**: Tailwind CSS with custom gothic & Hogwarts design tokens
- **Typography**: Cinzel, Cinzel Decorative, and Inter via `next/font/google`
- **Icons**: Lucide Icons & Custom SVG Sigils

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build & Run for Production
```bash
npm run build
npm start
```

## 🎵 Background Music Configuration

Per legal copyright requirements, copyrighted movie audio files are not bundled in this repository.

1. To use your legally licensed soundtrack (e.g., Hedwig's Theme), place your MP3 file at:
   ```
   public/audio/background-theme.mp3
   ```
2. If this file is absent, the portfolio automatically generates an enchanting, royalty-free celestial Hedwig-inspired waltz using the browser's built-in **Web Audio API**!
